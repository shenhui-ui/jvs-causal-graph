# 陷阱 1–10：环境与通道

> **本页是技能 `jvs-graph-question-compatibility` 的附页**（2026-09-20 从 `SKILL.md` 拆出，**内容逐字未改**）。
> **何时读**：开跑前核对环境、换 provider / 换通道、排查「跑不起来」时。
> 入口、三步核验流程、第 4 步与全部附页索引见 `SKILL.md`。

---

1. **题集与图谱的编号空间必须核对**：R（既有语料 语料组A/语料组B）与 G（D10 新抽取）**不互通**。
2. **`targeted_round.py prepare` 写死 30 题**（`len(gold) != 30` 直接 `ValueError`），接不了 D10。
3. **`channel()` 硬约束**：生成端点必须是回环桥（`http == 127.0.0.1` + `/v1/chat/completions`
   + 无 userinfo/query/fragment），否则 `ValueError`。ark 直连**不满足**，需本地桥。
4. **生成端 `doubao2api` 在 PyPI 上不存在**，桥无法重装；DSH 也不能当桥（其 `/chat/completions`
   是**出站** `fetch(api.deepseek.com)`，`dsh-host-webserver` 仅注册 `/` 路由）。
5. **判分器分两套**：`eval_m1.py`（题集无关，吃 `answers.jsonl`+gold，默认 rule_heuristic）
   与 `llm_judge.py`（真实 LLM 语义判分）。基线 21/30 用的是**后者** + `llm_answer.py` 生成。
6. **口径不一致就不能比**：换生成/判分 provider 后，结果不得与 21/30、22/30 并列；
   留出集通过率**永远单列**。
7. **gold 必须是三要素结构**：`llm_judge.py` 的 `JUDGE_FIELDS = ("cause","effect","evidence_hint","available")`
   要求 `{cause, effect, evidence_hint}`。基线 `query-set-real-init.jsonl` 用 `gold_answer{cause,effect,evidence_hint}`。
   **自由文本数组（如「变更前/变更后/原因/处置」这类标签列表）不能出分** —— 开工前先核 gold 结构，
   否则构图 + 判边全做完仍拿不到正确数。
8. **基线生成通道是 `doubao_sub` 本地桥，不是 ark**：`llm_answer.py` 的 `PROVIDERS` 里
   `doubao_sub.url` 默认 `http://127.0.0.1:9090/v1/chat/completions`，由
   `aux_doubao_bridge.py`（FastAPI）转 `doubao2api.client.DoubaoChatClient`（豆包**订阅额度**，扫码登录）。
   跑基线前先确认：`doubao2api` 已安装 + `.doubao_session.json` 存在 + 端口 9090 在听。
   （`llm_answer.py` docstring 里写「用 sensenova」是**过期注释**，以 `generation.log`/`doubao-bridge.log` 为准。）

   ⚠⚠ **`doubao` 与 `doubao_sub` 是两个不同 provider，写错必 403**（2026-09-18 踩）：
   | 环境变量 | 实际打到 | 结果 |
   |---|---|---|
   | `LLM_PROVIDER=doubao` | **火山方舟官方** `ark.cn-beijing.volces.com` | 无 `DOUBAO_API_KEY` → **HTTP 403** |
   | `LLM_PROVIDER=doubao_sub` | 本地桥 `127.0.0.1:9090` | 正常 |
   **判别技巧**：桥本身 `curl /v1/models` 与 8-token 小请求**都能过**，
   只有真实生成请求 403 —— 极易误判成"凭证失效/限流"。
   看到 403 先查 `LLM_PROVIDER` 拼写，别急着排查桥。
   正确调用：`LLM_PROVIDER=doubao_sub DOUBAO_SUB_KEY=dummy LLM_MAX_TOKENS=4096`。
9. **写 JSON 产物一律「先写 `.tmp` + 校验 + `os.replace`」**：`io.open(path,"wb")` 会**先截断**，
   若随后序列化抛异常（例如误传函数对象而非调用结果），文件会变成 0 字节。已踩过一次（从 git 恢复）。
10. **`doubao2api` 在本机是「已装」的 —— 别把搜索根写错**（2026-09-16 假否更正）：
    搜索根必须是 **`C:\Users\<user>\.workbuddy`**（无 `-ai`！），包在
    `~/.workbuddy/binaries/python/envs/default/Lib/site-packages/doubao2api`（v0.2.0），
    解释器 `~/.workbuddy/binaries/python/envs/default/Scripts/python.exe`（3.13.14），
    且 `fastapi`/`uvicorn`/`pydantic`/`httpx` **全部已装**。
    **托管解释器 `.workbuddy-ai\...3.13.12` 里没有这些包** —— 桥必须用 `.workbuddy` 那个 Python。
    会话文件：`01-host-product/2026-08-28-20-59-40/docs/host_memory_dump/.doubao_session.json`。
