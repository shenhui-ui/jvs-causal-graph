# 实验报告的独立复核

## 何时用

- 要复核一份实验 / 评测报告（作者自查过、但**未获第二方验证**）
- 报告给出「A 显著优于 B」类**差值结论**，需要判断能不能采信
- 报告主表数字看着对，但**根因 / 解释段**读起来可疑
- 引用报告数字前，要确认它与产物是否一致
- 报告声称某字段 / 某行为不存在，但你没在产物里验证过

## 一句话

**指标表全对 ≠ 报告可信。** 复核必须覆盖**根因 / 解释段**，并且要问「**这个对比实验测的到底是什么**」。

## 判据 1：复算范围必须覆盖「根因 / 解释段」

**实测（2026-09-30，某两臂对比报告）**：

| 段 | 复算结果 |
|---|---|
| §2 指标表 6 行 | ✅ **逐项全对** |
| §1 图谱规模 4 项 | ✅ **全对** |
| **§0 / §3.1 的根因数字** | ⚠️ **25/40 与实际 17/40 不符** |

⇒ **只看主结果表会漏掉错的那一段。** 根因段的数字有三个特征：
① 更少被人复算；② 更容易凭印象写；③ **会被后续文档（含生成器）引用传播**。
（该数字当时已复制进 `_migrate/status_map.py` ⇒ 渲染进待办清单。）

**动作**：逐条列出报告的**每一个可复算断言**（不只主表），逐条给判据命令。

## 判据 2：数字不符 vs 口径差异 —— 穷举后再判

作者通常**不给口径命令**。做法：

1. 先列出所有能想到的口径（逐项计数 / 阈值 / 字段 / 组合 / 时点）；
2. 逐个实测；
3. 全部无对应 ⇒ 判「**数字不符**」；
4. ⚠️ **穷举无对应 ≠ 作者造假** —— 如实写「**未找到对应口径**」，不下动机结论。

**实测口径穷举（8 种均无目标值）**：`chain==0` 17 ｜ `ev==0` 17 ｜ `chain<=1` 31 ｜
`ev<=2` 31 ｜ 否定词 8 ｜ 组合 21 ｜ `anchors==0` 3 ｜ `nb==0` 40。

## 判据 3：对比实验的「口径有效性」量化（最容易被忽略）

**两臂差值大 ≠ 机制差异大。** 先量化三件事：

| 量化项 | 手法 | 判据 |
|---|---|---|
| ⭐ **gold 证据出处的 top-k 命中率**（**首选 —— 直接测目标量**） | 逐题取 gold 的**证据字段** → 定位其所在**场景文件** → 查该文件是否出现在检索结果的 `path` 里 | 命中率 **22/23 = 95.7%**（唯一 miss `C07`）⇒ 证据出处**基本都在检索面内** |
| **gold 的出处重合度** | gold 的答案 / 证据字段对语料的 **n-gram 覆盖率** | 高覆盖（如 **0.84**）⇒ 答案出处**在语料里**（⚠️ **≠ 在检索面里**） |
| **反恒真对照** | 随机文本同法计算覆盖率 | 必须**显著低于**被测项（实测 0.000），否则探针无分辨力 |
| ⛔ **信息面规模 —— 不得单独作判据** | 归一化字符数 / 文件数 | ⚠️ **体量小 ≠ 单次检索覆盖高**（取决于**分块粒度**）：实测 `startLine` **191/191 全为 1**（整文件粒度），单次 top-k 上限 **5/24 = 20.8%**；只有**跨题并集**才 24/24 |

⇒ 若「**gold 证据出处的 top-k 命中率高** + gold 出处重合度高」，则该实验实际度量的是**信息形态保真度**
（叙事原文 vs 结构化抽取），**不可作「能力 / 价值」判据**（跨轴引用，本地红线 18 同族）。

**实测**：某对比实验的语料面 **6,352 B / 2,565 归一化字符**（24 场景），
`gold.evidence_hint` 对语料覆盖率 **0.839**（23/40 逐字可寻），
且**逐字可寻的 23 题中 22 题（95.7%）证据所在场景被 top-5 取回**
⇒ 该实验测的是形态保真度，其 −58.33pp 不可外推为「能力劣势」。
⚠️ **注意这条实测的来源**：它是**直接测目标量**得到的，**不是**从语料体量推断的 ——
初版由「语料只有 6 KB」推断「检索面接近全覆盖」，**该推断是错的**（见「坑 1」）。

## 一条纪律：假设先测后撤

复核中自己提出的**机制假设**必须用数据测过再采信。

**实测**：初判「A 臂在照抄语料所以得分高」——
测 `gold.cause` 覆盖率仅 **0.316**（cause 是提炼表述、非照抄）
⇒ **假设不成立，显式撤回并写进留痕**（本地红线 10：先怀疑自己的检查代码 / 假设）。

## 常见失配形态

| 形态 | 实例 |
|---|---|
| 报告自述的**字段名与产物不同** | 报告写「没有 `理由:` 行」，产物模板实为「**原因：/结果：/证据：**」，且该行 40/40 存在 |
| 报告**数字与产物计数不符** | 25/40 vs 17/40 |
| 结论**方向对但依据被夸大** | 「模板无原因可引」方向成立，但量级与表述不实 |
| 报告自述**通路 / 环境与产物不符** | 需查执行日志与产物时间戳 |

## 留痕与订正边界

- 按项目的第二方复核协议留痕：**复核者 / 复核范围（逐条）/ 复核方式（判据命令）/ 结果（逐条）/ 自身局限**。
- ⚠️ **复核者不得修改被复核产物** —— 但**纯机械可复现的数字**（计数、字段名）可订正，前提三条：
  ① **原文痕迹保留**；② 留痕里**声明「同一执行者既复核又订正」**；③ **结论方向不动**。
- **生成物传播面**：若该数字已复制进生成器（如 `status_map.py`），必须 `git grep -rn "<旧值>"` **全库扫**；
  只有「全库命中只剩留痕引用」才算改完 —— 否则生成器会在下一轮把旧值**重新印回**。

## 坑

1. ⭐⭐ **「信息面小 ⇒ 检索覆盖高」是错误启发式** —— **体量小不蕴含单次覆盖高**，取决于**分块粒度**。
   实测：语料 6 KB / 24 文件，但 `startLine` 全为 1（整文件粒度）⇒ 单次 top-5 上限 **5/24 = 20.8%**；
   只有**跨题并集**才是 24/24。
   ⚠️ **该错误能通过「反恒真对照」** —— 因为对照只测「探针有没有分辨力」，
   **不测「这个量是不是我要证的那个量」**。⇒ 修法：**直接测目标量**（top-k 命中率），不要从体量推断。
2. **同一文档内可以自相矛盾** —— 口径表里已列出 `chain<=1 = 31`，正文却写成「链 ≤2 跳」（实为 **34**）。
   ⇒ **穷举口径后必须回头核对正文措辞**，不能只在表里列全。
3. **主指标与根因数字是两个独立可信度** —— 主表可能被反复复算，根因段几乎没人查。
4. **索引脏时 `git diff HEAD` 会误导** —— 共享索引把新文件记 `D` 时，
   `git diff HEAD --stat` 报「N deletions」，而**工作区文件一直在**。
   判据：`git hash-object <工作区>` == `git rev-parse HEAD:<path>`（逐字节比），
   或用「`status` 非空 + `git diff HEAD` 为空 = 索引里是旧版」。
5. **别用「报告没给口径」当「作者错」** —— 如实写「未找到对应口径」。
6. **别只扫「作者给的口径」** —— 作者常把口径写在另一份文档（执行口径 / 决策材料包）里，要顺链读。
7. **`nb` / 未填充字段**：产物里恒为 0 的字段（如 40/40 `nb=0`）应作为「疑未填充」登记，
   **不得**当作「实测为 0」的证据。
8. ⭐ **探针的自测数据必须写进产物文件** —— 若只 `print` 到 stdout，按文档给的复跑路径**无法复现**。
   （实测：语料规模行原只在 stdout，`OUT` 文件里没有 ⇒ 已被第三方复核拦下。）
9. **「机制是否成立」属语义判断，不要越界** —— 复核只能断言「与产物一致」；
   若自己在别处声明过「未覆盖语义面」，**不得**又在结论里写「机制判断成立」。
